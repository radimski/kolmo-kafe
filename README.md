# Website Workspace

A Next.js starter for building websites with TypeScript and Tailwind CSS.

## Stack

- **Next.js 16** (App Router)
- **React 19**
- **TypeScript**
- **Tailwind CSS 4**

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:43123](http://localhost:43123) to preview the app.

## Project structure

```
src/
  app/           # Pages, layouts, and routes
  components/    # Shared UI components (add as needed)
projects/        # Notes and folders for individual website projects
public/          # Static assets
```

## Scripts

| Command        | Description              |
| -------------- | ------------------------ |
| `npm run dev`  | Start development server |
| `npm run build`| Production build         |
| `npm run start`| Run production server    |
| `npm run lint` | Run ESLint               |
